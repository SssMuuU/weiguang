微光 Windows 版 0.2.1

安装：关闭正在运行的微光，运行新版 .msi 安装程序，确认原安装位置并完成安装；不必先卸载。完成时勾选“打开微光”。
之后可在窗口底部检查并下载更新，通过校验后使用 Windows 安装向导升级。若取消安装，可以从原快捷方式重新打开。

计划、习惯和记录保存在 %LOCALAPPDATA%\\Weiguang\\BrowserData。安装和升级不会清空该目录，仍建议定期导出 JSON 备份。
应用完整包含离线页面；只有检查和下载更新需要联网，不上传个人计划或记录。
便携 ZIP 必须完整解压后运行“微光.exe”，不要单独复制 EXE。若选择便携方式，后续 MSI 更新会转为安装版。

系统要求：Windows 10 / 11（64 位），以及 Microsoft WebView2 Runtime。
新版使用 Windows 标准 MSI 安装、回退与卸载机制，不再使用自制解包安装器。
0.2.0 EXE 安装器已撤回，请不要恢复被隔离的文件。
扫描通过不代表所有安全软件都会放行；若出现病毒告警，请停止安装，不要关闭防护或添加排除项。
