微光 Windows 便携版 0.1.0
========================

双击“微光.exe”即可打开，无需安装，也不需要管理员权限。

第一次使用：
1. 保持网络连接，打开微光。
2. 选择“从空白开始”或“先看看示例”。
3. 首次完整载入后，核心页面可离线使用。

数据说明：
- 计划、习惯、待办和记录保存在当前电脑的浏览器配置中，不会上传到微光服务器。
- 换电脑、重装浏览器或清理网站数据前，请在右上角“微”→“数据与安装”中导出 JSON 备份。
- 在另一台电脑打开微光后，可通过“恢复备份”导入该文件。

运行要求：
- Windows 10 或 Windows 11。
- 推荐已安装 Microsoft Edge；也支持 Google Chrome。若两者都未找到，会使用系统默认浏览器。
- 第一次打开需要联网，之后离线能力取决于浏览器缓存是否已完整建立。
