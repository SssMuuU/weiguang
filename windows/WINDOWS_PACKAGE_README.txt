微光 Windows 版 0.1.0
===================

推荐使用“微光安装程序-0.1.0.exe”安装。安装时可以选择位置；完成后可从桌面或开始菜单直接打开微光，不需要再在应用内点击安装。

压缩包是备用便携版：完整解压后双击“微光.exe”即可运行，不能只单独复制 exe。

网络说明：
- 应用页面已经包含在安装包内，运行时不访问 chatgpt.site，也不需要联网。
- 程序只在本机 127.0.0.1:17895 提供页面，不会向局域网或互联网开放。

数据说明：
- 计划、习惯、待办和记录保存在当前电脑的微光专用浏览器配置中。
- 换电脑或清理应用数据前，请在右上角“微”→“数据与安装”中导出 JSON 备份。
- 在另一台电脑打开微光后，可通过“恢复备份”导入该文件。
- “恢复示例数据”和“清空全部数据”是两个独立操作，执行前都会再次确认。

运行要求：
- Windows 10 或 Windows 11。
- 微光使用 Windows WebView2 Runtime 在自己的原生窗口中显示界面，不会再打开 Edge 浏览器窗口。
- 绝大多数 Windows 10/11 已包含 WebView2 Runtime；若系统确实缺少，请先通过 Windows Update 更新。
- 安装程序会安装到当前用户目录，并创建桌面和开始菜单快捷方式，不需要管理员权限。
- 由于没有商业代码签名证书，Windows 首次运行时可能显示来源提醒。
